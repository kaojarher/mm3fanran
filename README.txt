凡人修仙傳：Emoji 仙途（PWA 版）

【怎麼安裝成 App】
PWA 必須透過 https 網址開啟才能安裝（直接雙擊 index.html 只能玩，不能安裝）。
1. 把這個資料夾裡的所有檔案原封不動上傳到任一靜態網站空間，例如：
   GitHub Pages、Netlify（把資料夾拖進去）、Cloudflare Pages、Vercel。
2. 用手機或電腦開啟那個網址：
   - iPhone／iPad：Safari →「分享」→「加入主畫面」
   - Android：Chrome 選單 →「安裝應用程式」
   - 電腦：Chrome／Edge 網址列右側的「安裝」圖示
   遊戲內「⚙️ 設定 → 📲 安裝到裝置」也能一鍵安裝（瀏覽器支援時）。
3. 第一次載入後即可離線遊玩，存檔保存在該裝置上。

【更新遊戲】
改了 index.html 之後，把 sw.js 第 2 行的 VERSION 加 1（例如 fr-v2），重新上傳，
已安裝的裝置下次開啟並重新整理後就會更新。

【檔案】
index.html            遊戲本體
jspdf.umd.min.js      PDF 摺頁小冊用（已內建，離線可用）
three.min.js          3D 引擎（已內建，離線可用）
manifest.webmanifest  App 資訊
sw.js                 離線快取
icon-*.png            圖示（🧝，未更動）


【主題改版說明】
本版只更動名稱與劇情文字，遊戲系統（數值、戰鬥、掉落、存檔格式）未變。
存檔欄位已改名（fr_ 開頭），舊版「魔法門」的存檔不會被讀取，這是為了避免舊職業名稱造成錯誤。

【修仙小說（新增）】
Puter AI 會把你的冒險寫成連載小說，名為《凡人仙途紀》（📖 手冊 → 📜 修仙小說，或按 N 鍵）。
- 即時模式（預設開啟）：在秘境中事件累積滿 8 分，戰鬥結束後就會立刻寫成一集；回到坊市時也會成章。可在小說選單切換成「只在回坊市時」。
- 第一次使用請在小說選單點「登入 Puter」（寫作需要連網）；未登入或離線時會用內建範本寫成，之後可用「用 AI 重寫本集」。
- 可匯出 MD、HTML 電子書、TXT、A4 摺頁小冊 PDF。章節與存檔一起保存。
- 提示詞要求使用原創人物與情節，不使用原著角色、不照搬原著情節。
